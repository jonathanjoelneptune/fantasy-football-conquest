Markdown-aware rich paste is enabled. You can paste the Chronicle exactly as ChatGPT gives it, including #, ##, ###, **bold**, and *italics*. The editor automatically converts those markers into the same visual hierarchy. Rich text from Word or Google Docs is also retained. Each week has its own local draft.

Publishing flow

Preview reads this browser's current draft directly, so you can inspect the full newsletter before committing. Publish copies the finished HTML and opens the correct authenticated GitHub editor. For a brand-new week it opens GitHub's New file screen instead of a dead edit link. Paste once and commit. A truly one-click commit from this public Pages site would require a private authenticated backend or GitHub App; no repository token is stored here.
