# Fantasy Football Conquest

Interactive fantasy-football conquest map, live War Correspondent, season Big Board, and historical Chronicle.

- Public site: https://jonathanjoelneptune.github.io/fantasy-football-conquest/
- Commissioner route: `/comish/` (additional in-app unlock still required)
- Current release: v8.07

The site is a portable static HTML application. Live league data is read from Sleeper and NFL scoreboard feeds in the browser; no private API keys are stored in the repository.
